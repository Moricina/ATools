## 💡 设计理念：为什么是「双独立面板」？

在 macOS 上，大多数用户面临着两难选择：
- **原生 Launchpad**：满屏铺满图标、不支持细致分类与启动参数定制、查找低频软件极其繁琐；
- **全能型启动器（如 Raycast / Alfred）**：功能丰富但体积庞大，往往集成了太多绝大多数用户根本用不到的插件生态，内存常驻动辄上百兆。

**ATools 的核心哲学是「解耦、纯粹、极速」**：
1. **物理级双面板解耦**：将日常最高频的「应用分类整理与启停」与「全盘极速检索与即时工具」彻底分离，互不干扰；
2. **零第三方依赖与零 Electron 臃肿**：纯原生 Swift + AppKit 手工精雕细琢，运行流畅如丝；
3. **原子互斥调度器 (`PanelCoordinator`)**：双快捷键（`⌥A` 与 `⌥Space`）毫秒级原子切换，绝不发生窗口重叠、冲突与闪烁，点击外部即刻退让并优雅归还工作区焦点。

## 🗂️ 核心面板 A：Maye Nano 风格分类工作台 (`⌥A`)

针对 Mac 上杂乱无章的桌面与启动台，ATools 提供了媲美 Windows 极简神级启动器 **Maye Nano** 的分类工作台：

```
 ┌────────────────────────────────────────────────────────┐
 │  [ 常用 (12) ]   [ 办公协作 (8) ]   [ 影音娱乐 (6) ]  + │  ← 自适应胶囊栏
 ├────────────────────────────────────────────────────────┤
 │   [图标]     [图标]     [图标]     [图标]     [图标]    │  ← 350ms 浮起微动效
 │   微信       飞书       Safari     Xcode     终端      │  ← 实时插队平滑让位
 │                                                        │  ← 跨分类虚影占位
 │   [图标]     [图标]     [图标]     [图标]     [图标]    │
 └────────────────────────────────────────────────────────┘
```

### 1. 极致丝滑的手势与拖拽排版
- **三段式自适应液态胶囊标签（CategoryPillView）**：融合 SF Symbol 矢量图标 + 自定义分类名 + 动态数量角标，悬停聚能高亮，自适应深浅色高光描边；
- **拖拽悬停自动切页（Spring-Loaded Category Pill）**：拖拽任意图标至分类胶囊上方悬停 **280ms** 即可自动丝滑切换到目标分类，支持 `Esc` 键或拖出窗外一键反向回滚；
- **触控板双指横向滑动切页**：在抽屉面板任意位置双指左右滑动，即可如翻书般平滑切换不同分类；
- **长按 350ms 浮起反馈 + 快速拖拽双模响应**：轻点即刻启动，长按 350ms 触发触觉震动与微放大浮起，拖动时目标周围图标依据几何反算与 **14% 磁滞防抖** 实时平滑让位；
- **跨分类拖拽实时虚影占位槽（Cross-Category Live Ghost Slot）**：将应用从 A 分类拖至 B 分类网格中时，目标网格实时生成半透明虚影占位并引导让位，松手即刻精准落槽；
- **Alt (⌥) 键快速对调**：按住 `Option` 键拖拽图标至另一个图标上，即可精准对调二者槽位。

### 2. 启动项深度属性编辑器
- 选中任意图标右键点击 **「编辑项目...」**，即可呼出原生属性编辑器：
  - **自定义显示名称**：摆脱长串应用全名，精炼命名；
  - **自定义启动参数 (Launch Arguments) 与环境变量 (Environment Variables)**：为专业用户提供定制能力（如特定调试模式、指定配置文件启动）；
  - **指定工作目录 (Working Directory)**：避免部分脚本或终端工具找不到运行上下文；
  - **拼音与多音字搜索标签 (Tags)**：添加自定义搜索别名（例如为微信添加“wx”、“聊天”），在全盘搜索中秒级命中；
  - **一键导入并安全托管自定义图标**：支持将外部 `.png`、`.icns`、`.jpg` 或其他 `.app` 图标拖入替换，由 ATools 沙盒独立安全托管，即使源文件删除图标依然清晰显示。

### 3. 失效启动项全链路感知与自愈维护
- 抽屉加载与设置面板全链路实时检测目标文件存活状态；
- 当某款应用被移动、更名或卸载时，图标自动呈现**精致灰阶与感叹号角标**；
- 右键提供 **「重新定位目标...」**（一键选取新路径恢复）与 **「一键清理失效项」**（自动清理无效启动项并回收孤立的托管图标缓存）。

### 4. 自描述配置备份、干跑预校验与快照回滚
- **全量配置导出**：一键导出包含 `config.json`、分类结构与全部托管自定义图标的 `.atoolsbackup` 归档包；
- **导入前内存深度校验**：利用 SHA-256 校验归档完整性，防范损坏文件破坏配置；
- **自动创建导入前快照**：恢复前在内存和本地自动保留恢复前快照，支持随时「一键回滚快照」；
- **跨机器家目录迁移路径自愈**：当备份从 `/Users/alice` 迁移至 `/Users/bob` 时，自动修正绝对路径前缀，无缝开箱即用。

## 🔎 核心面板 B：Spotlight 风格全盘搜索中枢 (`⌥Space` / `⌘Space`)

对标并全面超越 macOS 原生 Spotlight 聚焦与 Raycast，提供毫无延迟的打字即出搜索体验：

```
 ┌────────────────────────────────────────────────────────┐
 │ 🔍  Safari|                                            │  ← 居中流线型大搜索条
 ├────────────────────────────────────────────────────────┤
 │  [ 搜索结果 (Top-N) ]     [ 快捷过滤：全部 / 应用 / 文件 / 文件夹 ]
 │                                                        │
 │  🌐  Safari 浏览器             /Applications/Safari.app│  ← 0ms 内存极速索引
 │  📁  Safari 书签同步           ~/Library/Safari        │  ← CoreServices 检索
 │  📄  Safari_Dev_Notes.pdf     ~/Documents/Notes       │  ← 智能档位归并排序
 └────────────────────────────────────────────────────────┘
```

### 1. 0 毫秒 App 极速搜索
- **内存常驻热点应用索引**：启动时自动扫描本机安装的所有应用并建立拼音与简拼索引；
- **全拼、简拼与多音字全覆盖**：输入 `zd` 秒出“访达”，输入 `wx` 秒出“微信”，输入 `wyy` 秒出“网易云音乐”；
- **系统后台脏进程智能过滤**：自动净化系统内置无界面后台 Helper、CrashHandler 等干扰项，呈现最干净的应用列表。

### 2. 毫秒级全盘文件检索（直连系统内核索引）
- **无自建数据库、零额外磁盘扫盘能耗**：不同于第三方软件粗暴的后台轮询扫盘，ATools 直接向系统底层 CoreServices `MDQuery` 索取检索结果，**不占磁盘 I/O，不耗电，毫秒级流式直出**；
- **本地化文件夹全兼容**：完美支持 macOS 本地化系统文件夹（如 `Virtual Machines.localized` 识别为“虚拟机”，`Documents` 识别为“文稿”），输入中文或英文均能精准秒开；
- **智能档位归并排序**：精确匹配 > 前缀匹配 > 目录快照 > 模糊匹配，最近访问与高频文件自动置顶。

### 3. Alfred 风格全盘搜索排除引擎 (Search Exclusion Engine)
- 许多用户全盘搜索被海量缓存垃圾与构建产物污染，ATools 内置了强大的排除引擎：
  - **6 大常用预设（设置中为 3行×2列 紧凑磁贴）**：
    - 排除系统与应用缓存（`~/Library/Caches`、WebKit 缓存）
    - 排除资源库（`~/Library`，智能特赦保留 iCloud 云盘与常用网盘）
    - 排除系统日志与崩溃堆栈（`~/Library/Logs`、`DiagnosticReports`）
    - 排除废纸篓与临时目录（`~/.Trash`、`/tmp`）
    - 排除开发依赖与产物（`node_modules`、`DerivedData`、`.build`、`target`、`__pycache__` 等）
    - 排除版本控制与隐藏文件（`.git`、`.svn` 及以 `.` 开头的隐藏项）
  - **自定义排除黑名单**：支持直接从访达将任意文件夹拖拽至偏好设置，永久屏蔽其进入全盘搜索。

### 4. 搜索框语法胶囊 (Syntax Token Capsule) 与剪贴板自动粘贴
- **空格一键切入文件检索**：输入空格瞬间转入纯文件检索模式，按 Backspace 优雅退回；
- **视觉胶囊状态机**：输入搜索语法指令（如 `/app`、`/file`、`/folder`）自动聚拢为精美胶囊，占位符动态切换；
- **复制后唤出自动粘贴**：在外部应用中复制文本后短时间（3 秒）内唤出全盘搜索，自动填入复制文本开始检索，附带敏感信息与凭据自动阻断防护。

### 5. 丰富开箱即用的内置扩展工具
- 🧮 **实时科学计算器**：输入 `(1024 * 768) / 2`、`0x10 + 32` 或复杂嵌套算式即时求解，按下回车自动将结果复制到剪贴板；
- 📖 **系统离线权威词典**：调用底层 `DCSCopyTextDefinition` 接口，输入英文单词秒级展开权威中文释义，回车直达系统词典 App；
- ⚙️ **系统控制极速指令**：
  - `lock`：即时锁屏
  - `sleep`：进入睡眠
  - `trash`：一键清空废纸篓（带防误触确认）
  - `restart`：重启系统
  - `shutdown`：关机
- 🌐 **网络搜索回退**：本地无匹配项目或回车确认时，调用系统默认浏览器一键跳转至 Google、Baidu、Bing、DuckDuckGo 或自定义搜索 URL。

## 🚪 系统黑科技：关窗退出应用 (AutoQuit)

在 macOS 上，“点击红叉关闭窗口但应用仍在后台常驻”是长期困扰许多新老用户的痛点。ATools 原生内置了对标 SwiftQuit 的 **AutoQuit** 引擎：

- **确诊铁律：AX 与 WindowServer 双重权威交叉核验**：
  - 传统类似工具仅监听 Accessibility（AX）事件，在切换应用、失焦、多虚拟桌面（Spaces）切换时极易因 AX 节点瞬态清空而**严重误杀正在使用的应用**；
  - ATools 穿透操作系统底层 WindowServer，实时比对物理窗口树与图层状态。**只有当用户显式点击红叉真正关闭窗口、且该应用已无任何可见窗口时，才调度退出**，彻底免疫应用失焦带来的误杀；
- **双模式自由切换**：
  - **「全部应用（名单为排除项）」**：全局生效，自由勾选保留需要常驻的应用（如网易云音乐、钉钉、微信等）；
  - **「仅退出名单」**：仅对指定添加的应用生效，适合只针对少数特定软件关闭时退出；
- **0–5 秒防误关延迟缓冲**：留出短暂时间窗口，避免不小心误点红叉立即中断进程；具备未保存文档保护与 Dock 最小化/隐藏窗口智能保护。

## 🛑 彻底关闭与替换系统聚焦 (Spotlight) 指南

在 macOS 上，“彻底替换聚焦”包含两个层面：**关闭 Spotlight 前台快捷键与菜单栏图标**，以及**让 ATools 接管全局调用**。

### 步骤 1：禁用系统聚焦的快捷键（释放 Cmd + Space）
1. 打开 macOS **「系统设置」** (System Settings)；
2. 在左侧导航栏找到并点击 **「键盘」** (Keyboard)；
3. 点击右侧的 **「键盘快捷键...」** (Keyboard Shortcuts...) 按钮；
4. 在弹出窗口左侧导航选择 **「聚焦」** (Spotlight)；
5. **取消勾选** 以下两项：
   - ☑️ **显示“聚焦”搜索**（原快捷键为 `⌘ Space`）
   - ☑️ **显示“访达”搜索窗口**（原快捷键为 `⌥⌘ Space`）
6. 点击「完成」保存。此时 `Cmd + Space` 已完全被系统释放，不再有任何冲突！

### 步骤 2：从右上角菜单栏移除聚焦放大镜图标
1. 再次打开 **「系统设置」** -> 左侧点击 **「控制中心」** (Control Center)；
2. 向下滚动找到 **「聚焦」** (Spotlight) 模块；
3. 将下拉选项从「在菜单栏中显示」改为 **「不在菜单栏中显示」**；
4. 此时 macOS 顶栏右侧的系统聚焦放大镜图标将彻底消失，桌面干净清爽。

### 步骤 3：让 ATools 接管日常全局搜索
* 打开 ATools 偏好设置 -> **「全盘搜索」** Tab；
* 点击「设为 ⌘Space」或在专属快捷键录制框中按下 `⌘Space`；
* 此时日常使用 `⌥A` 唤出分类工作台，使用 `⌘Space` 唤出全局搜索，全面替代并超越原生体验！
